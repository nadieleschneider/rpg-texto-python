# 🗺️ Jogo de RPG em Texto (Python)

Jogo de aventura e exploração em formato text-based desenvolvido em Python, estruturado com **Orientação a Objetos (OOP)**, persistência de dados em arquivos **JSON** e mapeamento dinâmico de salas e inventário.

## 🚀 Tecnologias Utilizadas
* **Python 3** (Linguagem principal)
* **Programação Orientada a Objetos** (Classes `Jogador`, `Sala`, `Item`)
* **Manipulação de Arquivos JSON** (Carregamento de mapas e sistema de save/load de progresso)

## 🎮 Como Jogar
1. Certifique-se de ter o Python instalado em sua máquina.
2. Baixe ou clone este repositório.
3. No terminal, navegue até a pasta do projeto e execute o arquivo principal:
   ```bash
   python main.py
